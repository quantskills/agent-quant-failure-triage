# 边界声明（QuantSkills 社区规则 §8）

- **数据来源**：PandaData（`panda_data` SDK）个股日线、指数日线、Barra 风格暴露、融资余额；策略账本与特征由用户提供。凭证只从环境变量或 `~/.pandadata/pandadata.env` 读取，仓库不含任何凭证。
- **假设条件**：反事实剥离假设各层规则可独立替换；风格贡献用日截面线性回归近似；成交按次日开盘一刀切成本；止损按收盘判定次日开盘执行。
- **参数**：观察窗、基准窗 120 交易日、IC 前瞻 5 日、PSI 阈值 0.10 / 0.25、组件失效阈值 −1%、外因解释比例 50%；全部可在 `config` 覆盖，见 `references/decision_rules.md`。
- **已知限制**：只给打分表时做不了事前预警；卡片未声明的层不做剥离；风格暴露依赖 PandaData 因子库覆盖，缺失时退化为指数代理；模拟器不是生产回测引擎，只用于同信号不同规则的相对比较；不处理分钟级执行与除权除息之外的公司行为。
- **风险边界**：输出是研究诊断与处置建议，不是交易指令；不自动下单；不承诺任何收益；不对任何个股或策略给出买卖建议。
- **性质**：QuantSkills Community Project，仅供量化研究与教育示例，不构成投资建议。未经 QuantSkills 维护者审核前，不代表任何官方立场。
