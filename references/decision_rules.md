# 裁决规则：顺序、阈值、禁令、证伪

## 一、裁决顺序（因果优先，不投票）

```
1. 数据层 failed（max PSI > 0.25 且 ≥30% 特征超阈）
      → 分布漂移 → 冻结 + 降仓 → ❌ 禁止重训 → 不再往下判
2. 外因：L2 warning（风格贡献 < −1% 且能解释 ≥50% 超额亏损）或 拥挤 warning
      → 风格环境断裂 / 拥挤踩踏 → 对冲 / 降仓 / 等待 → ❌ 禁止重训
      （同时列出组件层发现，作为附加处置）
3. 组件层：L4 / L5 / L3 反事实贡献 < −1%，或 L0 warning
      → 组件失效 → 只改那一层 → ❌ 禁止重训信号
4. 信号层：L1 failed（翻符号 + |t| > 1.5 + 变点落在观察窗）
      → 概念漂移 → ✅ 允许重训（只用变点之后的数据）或退役
   L1 warning（翻符号但未确认，或 |IC| 缩到基准 30% 以下且变点确认）
      → 降仓观察 → ⏸ 暂不重训
5. 都不成立 → 健康 / 证据不足
```

为什么这个顺序：上游不可信时下游读数没有意义（数据层最先）；外因能解释时动模型是在极端样本上学噪音（外因先于内因）；组件坏了重训信号解决不了问题（组件先于信号）。

## 二、默认阈值（`triage.py DEFAULT_CONFIG`，均可通过 `config` 覆盖）

| 参数 | 默认 | 含义 |
|---|---|---|
| baseline_days | 120 | 基准窗长度（交易日），紧贴观察窗之前 |
| horizon | 5 | IC 前瞻期：t+1 开盘买入 → t+1+h 收盘 |
| warmup_days | 30 | 模拟预热，保证基准窗起点已有持仓 |
| psi_warn / psi_fail | 0.10 / 0.25 | PSI 观察 / 失效阈值 |
| component_min_loss | 0.01 | 组件层反事实贡献低于 −1% 才算失效 |
| external_share | 0.5 | 风格贡献占超额亏损比例 ≥ 50% 才判外因主导 |

层内阈值（`layers.py`）：L0 池变动率 > 30% 或触板占比上升 > 3pct 或停牌 > 5% → warning；L4 whipsaw 率 ≥ 50% 且贡献 < −1% → warning；L5 锁死率 > 10% 或持仓票中位成交额比 < 0.6 或贡献 < −1% → warning；拥挤：相关性 +0.15、成交额占比 ×1.3、尖峰下跌日 ≥ 2 三项中两项 → warning。

## 三、重训禁令（intervention gate）

| gate | 含义 |
|---|---|
| forbidden | 当前禁止用最近数据重训：分布未回归 / 外因主导 / 组件失效 |
| hold | 暂不重训：证据未确认，先降仓观察 |
| allowed | 允许重训：外因与组件层已排除，信号逻辑确认失效 |

## 四、证伪条件与复核触发

每个结论必须附：
- **证伪条件**："如果出现 X，说明我判断错了，改判 Y"。例：若风格价差收敛后策略仍跑输且 IC 不恢复 → 改判概念漂移。
- **复核触发**：到条件自动重跑。例：中证 1000 − 上证 50 二十日价差回到 ±5%；科创 50 二十日年化波动 < 30%；L1 二十日 Rank IC 均值回到基准一半以上。

## 五、置信度

按证据强度给 0–1 的粗置信度（分布漂移 0.9；风格 0.6 + 0.3 × 解释比例；组件 0.7；概念漂移确认 0.75 / 未确认 0.45；健康 0.7）。这是排序用的相对量，不是概率。
